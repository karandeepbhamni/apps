# Zakariya Dola 1080P - PC + Android

## Sabse easy: GitHub se auto-build (kuch install nahi karna)
1. github.com pe free account -> New repository (private bhi chalega)
2. Is poori folder ko upload karo (Add file -> Upload files; `.github` folder bhi)
3. Repo -> Actions tab -> "Build EXE + APK" -> Run workflow
4. 5-10 min baad run kholo -> neeche Artifacts: `windows-exe` (setup + portable .exe) aur `android-apk`

## PC (local build)
cd desktop
npm install
npm start        # direct chalao
npm run dist     # .exe banao -> desktop/dist/

## Android (local build)
Android Studio mein `android/` folder open karo -> Build > Build APK(s)

## Use
App khulne par dola.com mein login karo, video generate karo.
Video card pe "1080P Master" button, ya neeche-right "⬇ 1080P" panel (Save / Download All / Auto-download).
PC: Downloads/Zakariya_Dola_Videos/   Android: Downloads/Zakariya_Dola_Videos/
